## What's New in SkyDrop TV v1.0.44

- **In-App GitHub Releases Updater**: Automated release checks, SHA-256 verification, and seamless in-place APK installation using D-pad controls.
- **Multi-Release Isolation**: Dedicated TV release filtering ensuring the TV app only consumes Android TV packages.
- **Animated Splash Screen**: Two-tone branding entrance animation with smooth focus transitions.
- **Media Viewer Controls**: Auto-hiding overlay controls for video and photo previews with remote wake-up.
- **Background Transfer Progress**: Real-time incoming transfer notifications and progress card at the bottom-right of the screen.
- **Dynamic Version Reporting**: Accurate runtime version resolution from Android package metadata.
